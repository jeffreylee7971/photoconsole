photoconsole/hasher.py exports:
- def sha256_file(path: str | Path) -> str
    Streams the file in CHUNK_SIZE byte chunks and returns lower-case hex sha256.

- def process_file(path: str, source_name: str, source_type: str) -> dict
    Returns a dict ready for upsert_media_file. Keys: path, hash, size, mtime, ctime, source_name, source_type, media_type, status, error_type, date_taken, camera_model, orientation, gps_lat, gps_lon.
    media_type is determined by extension: 'photo' if ext in PHOTO_EXTENSIONS, 'video' if in VIDEO_EXTENSIONS, else 'photo' is NOT applied — the caller should filter unknown extensions out first (scanner does), but defensively process_file returns status='error' with error_type='read_error' if extension is unsupported.
    On success: status='ok', error_type=None.
    On any Exception during hash or metadata extraction: status='error', error_type=ErrorType value from classify_error (or 'hash_failed'/'metadata_failed' for known operation-specific failures), hash may be None if hashing itself failed.
    Size/mtime/ctime are read from os.stat() and ALWAYS populated when the file exists (even on metadata failure).

- def process_files(file_candidates: list[tuple[str,str,str]], max_workers: int, progress_cb=None) -> Iterator[dict]
    file_candidates is a list of (path, source_name, source_type) tuples. Yields result dicts as workers complete (via concurrent.futures.as_completed). If progress_cb is provided, it is called as progress_cb(completed_count, total) after each result. Never raises; per-file failures become status='error' records.

photoconsole/metadata/photo.py exports:
- def extract_photo_metadata(path: str | Path) -> dict
    Returns dict with keys: date_taken, camera_model, orientation, gps_lat, gps_lon. All values may be None. Never raises — malformed/missing EXIF yields {k: None, ...}.
- def gps_to_decimal(dms_rationals, ref: str) -> float | None
    Internal helper, also exported for testing.

photoconsole/metadata/video.py exports:
- def check_ffprobe_available() -> None
    Raises RuntimeError with install instructions if `ffprobe -version` cannot be invoked.
- def extract_video_metadata(path: str | Path) -> dict
    Returns dict with keys: date_taken, gps_lat, gps_lon (and camera_model=None, orientation=None for shape parity with photo). Never raises — ffprobe failure or missing tags yield all-None.
- def parse_iso6709(s: str) -> tuple[float | None, float | None]
    Parses '+DD.DDDD+DDD.DDDD/' style strings; returns (None, None) on any parse failure.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File contents -> piexif | Image bytes may be malformed; piexif can raise. |
| File contents -> ffprobe | Video container may be malformed; ffprobe may fail or hang. |
| ffprobe stdout -> json.loads | ffprobe is trusted (system binary), but its output is parsed defensively. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service | piexif on malformed EXIF | mitigate | `try/except Exception` around piexif.load; return all-None dict (D-11). |
| T-03-02 | Tampering | subprocess invocation of ffprobe | mitigate | Always pass argv as a list, never shell=True; never interpolate filenames into a string. |
| T-03-03 | Denial of Service | ffprobe hang on bad video | mitigate | subprocess.run timeout=60; on timeout, treat as ffprobe failure (all-None metadata, not raise). |
| T-03-04 | Denial of Service | Decompression bomb via Pillow | mitigate | Rely on Pillow's default MAX_IMAGE_PIXELS limit; do NOT call Image.MAX_IMAGE_PIXELS = None. piexif reads EXIF headers without full decode, so this is mostly preventive. |
| T-03-05 | Denial of Service | OOM from non-streaming hash | mitigate | sha256_file streams in CHUNK_SIZE chunks (Pattern 2). |
| T-03-SC | Tampering | Pillow / piexif supply chain | mitigate | Audited in RESEARCH.md Package Legitimacy Audit (both [OK], 10+ yrs). |
</threat_model>
