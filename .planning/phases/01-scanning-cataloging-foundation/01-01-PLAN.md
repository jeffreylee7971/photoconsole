<!-- This plan CREATES the contracts. Downstream plans depend on these exact signatures. -->

photoconsole/errors.py exports:
- class ErrorType(StrEnum) with members:
    PERMISSION_DENIED = 'permission_denied'
    READ_ERROR = 'read_error'
    HASH_FAILED = 'hash_failed'
    METADATA_FAILED = 'metadata_failed'
    NOT_FOUND = 'not_found'
    TIMEOUT = 'timeout'
- def classify_error(exc: Exception) -> str
    Returns one of the ErrorType string values based on exception type.

photoconsole/constants.py exports:
- MEDIA_EXTENSIONS: frozenset[str] = frozenset({'.jpg', '.jpeg', '.png', '.gif', '.mp4', '.mov', '.avi'})
- CHUNK_SIZE: int = 8 * 1024
- PHOTO_EXTENSIONS: frozenset[str] = frozenset({'.jpg', '.jpeg', '.png', '.gif'})
- VIDEO_EXTENSIONS: frozenset[str] = frozenset({'.mp4', '.mov', '.avi'})

photoconsole/config.py exports:
- @dataclass class Source: name: str; type: str ('local'|'rclone'); path: str=''; remote: str=''
- @dataclass class Config:
    sources: list[Source]
    catalog_path: str               # absolute, ~-expanded
    include_extensions: frozenset[str]
    exclude_patterns: list[str]
    hashing_max_workers: int
- def load_config(path: str|os.PathLike) -> Config
    Parses YAML, expands ~ in catalog_path, normalizes include_extensions to lower-case with leading dot, raises ValueError with helpful message on missing required keys (sources, catalog_path) or unknown source `type`.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.yaml -> Config loader | Untrusted user-supplied YAML may contain path traversal, shell metacharacters, or unexpected types |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | YAML parsing in config.py | mitigate | Use `yaml.safe_load` exclusively — never `yaml.load`; rejects arbitrary Python object construction. |
| T-01-02 | Tampering | Path traversal via catalog_path | mitigate | `os.path.expanduser` + `os.path.abspath`; document that catalog_path is whatever the user configured — Plan 02 will not write outside this single sqlite file. |
| T-01-03 | Denial of Service | Maliciously large YAML | accept | YAML files are user-owned local config; not externally received; size unbounded but practical files are <1MB. |
| T-01-SC | Tampering | pip install of declared dependencies | mitigate | RESEARCH.md Package Legitimacy Audit verified all packages on PyPI registry via slopcheck 0.6.1; all marked [OK]; no [SUS]/[SLOP]. No checkpoint required. |
