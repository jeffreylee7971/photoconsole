photoconsole/catalog/db.py exports:
- def create_catalog_engine(db_path: str | Path) -> Engine
    Creates parent directory if needed, opens SQLite engine with PRAGMA journal_mode=WAL, synchronous=NORMAL, busy_timeout=5000. Calls Base.metadata.create_all.
- def session_factory(engine: Engine) -> sessionmaker
- def upsert_media_file(session: Session, record: dict) -> None
    Upserts by `path`. Uses SQLite's `INSERT ... ON CONFLICT(path) DO UPDATE SET ...` via sqlalchemy.dialects.sqlite.insert. Does NOT commit — caller commits the batch.
- def upsert_many(session: Session, records: Iterable[dict]) -> int
    Convenience: applies upsert_media_file for each record and returns count. Caller still commits.
- def should_skip(session: Session, path: str, mtime: float) -> bool
    Returns True iff a row exists for `path` with status='ok' AND mtime equal to the given mtime. Always returns False for status='error' rows (D-03). Always returns False if no row exists.
- def get_known_record(session: Session, path: str) -> MediaFile | None  (helper for tests)

| Boundary | Description |

| External callers -> upsert_media_file | Record dict assembled by Plans 03/04 may have keys that don't match the schema; bad keys should raise, not silently corrupt the row. |
| SQLite file | Single-writer constraint requires WAL mode + busy_timeout. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | upsert_media_file unknown keys | mitigate | Validate every record key against MediaFile column names; raise ValueError naming the offending key. |
| T-02-02 | Denial of Service | Concurrent writers from threaded scan | mitigate | Single-writer design (workers return dicts; main thread upserts). WAL mode + busy_timeout=5000 as belt-and-suspenders. |
| T-02-03 | Information Disclosure | Catalog DB readable by other local users | accept | Local-first per NFR2; catalog stored under user-controlled path; permissions managed by OS. |
| T-02-04 | Tampering | SQL injection via record values | mitigate | All queries via SQLAlchemy parameterized statements; no string interpolation. |
| T-02-SC | Tampering | SQLAlchemy supply chain | mitigate | Already audited in RESEARCH.md Package Legitimacy Audit (SQLAlchemy 18+ yrs, [OK]). |
