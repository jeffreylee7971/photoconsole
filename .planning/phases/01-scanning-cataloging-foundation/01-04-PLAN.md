photoconsole/scanner.py exports:
- class LocalScanner:
    def __init__(self, source: Source, include_extensions: frozenset[str], verbose: bool = False)
    def iter_candidates(self) -> Iterator[tuple[str, str, str]]
        Yields (absolute_path, source.name, 'local') for every regular file under source.path whose extension is in include_extensions and which is NOT a symlink (or under a symlink directory).

- class RcloneScanner:
    def __init__(self, source: Source, include_extensions: frozenset[str], verbose: bool = False, timeout: int = 300)
    def iter_candidates(self) -> Iterator[tuple[str, str, str]]
        Calls `rclone lsjson --recursive --files-only <source.remote>` via subprocess.run with argv list. Parses JSON output. For each entry whose IsDir is False and whose Path's extension is in include_extensions, yields (f"{source.remote}{entry['Path']}", source.name, 'rclone').
        Raises RuntimeError with install instructions if rclone is not found (FileNotFoundError on subprocess.run). Raises RuntimeError with rclone's stderr if returncode != 0.

- def check_rclone_available() -> None
    Helper: `subprocess.run(['rclone', 'version'], ...)`; raises RuntimeError on FileNotFoundError.

- def scan_all(config: Config, verbose: bool = False) -> Iterator[tuple[str, str, str]]
    Dispatches each Source by type, yields the concatenated candidate stream. Logs (only when verbose) the name and count per source as each completes.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.yaml -> source.remote -> rclone subprocess | User-controlled remote names flow to a subprocess invocation. |
| Filesystem -> os.walk | Filesystem may contain symlink loops, hardlinks, special files. |
| rclone stdout -> json.loads | rclone is a trusted system binary, but its output is parsed defensively. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Shell injection via rclone remote name | mitigate | Always use subprocess.run with argv as a Python list. Never shell=True. Never f-string-interpolate remote into a shell command. |
| T-04-02 | Denial of Service | Symlink loop crashes scanner | mitigate | followlinks=False on os.walk + prune symlinked dirs from `dirs[:]` + skip symlinked files. |
| T-04-03 | Denial of Service | rclone lsjson hang on slow remote | mitigate | subprocess.run timeout=300 (configurable in RcloneScanner __init__). |
| T-04-04 | Tampering | rclone stdout JSON tampering | accept | rclone is a trusted system binary; output is parsed with `json.loads` (no exec/eval). Malformed JSON raises ValueError which becomes a clear error. |
| T-04-05 | Information Disclosure | Verbose log leaks remote names | accept | Remote names are user config, not secrets. rclone credentials live in ~/.config/rclone/rclone.conf and are never exposed by `lsjson`. |
| T-04-SC | Tampering | rclone system binary supply chain | mitigate | rclone is a documented system dependency (see Environment Availability in RESEARCH.md); not a Python package. Out of scope for slopcheck. Plan 05 surfaces install instructions at scan startup. |
</threat_model>
