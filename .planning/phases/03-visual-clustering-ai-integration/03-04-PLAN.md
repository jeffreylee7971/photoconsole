OpenCV API (per AI-SPEC Section 4 "Tool Use / Integrations"):
- `cv2.imread(path) -> ndarray | None` returns BGR by default; None on read failure
- `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) -> ndarray`
- `cv2.Laplacian(gray, cv2.CV_64F).var() -> float` — sharpness metric; higher = sharper
- `cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")` — pretrained classifier ships with opencv-python-headless
- `cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30)) -> ndarray of (x, y, w, h)`

Cascade load decision (per PATTERNS.md `photoconsole/quality.py` section): load `_FACE_CASCADE` once at module level — NOT inside worker. CascadeClassifier is read-only after load and is documented thread-safe for `detectMultiScale` calls.

QualityWeightsConfig interface (from Plan 03, photoconsole/config.py):
- Attributes: sharpness, resolution, faces, exif_completeness (each float in [0, 1], sum to 1.0)
- Default values: 0.45 / 0.30 / 0.15 / 0.10 (D-08)

MediaFile EXIF fields (from photoconsole/catalog/models.py — Phase 1):
- date_taken: Optional[str] (ISO-ish from EXIF/ffprobe)
- gps_lat: Optional[float]
- gps_lon: Optional[float]

EXIF completeness signal (per D-08 + AI-SPEC Section 5 "EXIF-absent quality ranking" eval dim):
- Score = 1.0 when date_taken IS NOT NULL AND both gps_lat AND gps_lon IS NOT NULL
- Score = 0.5 when date_taken IS NOT NULL but GPS missing (OR vice versa)
- Score = 0.0 when both date_taken and GPS missing
This is computed from the catalog row, NOT from the image file. Pass a MediaFile-like dict (path + date_taken + gps_lat + gps_lon) to exif_completeness_score.

Normalization (per D-10 + Claude's discretion in CONTEXT.md "Normalization formula for quality signals (min-max or percentile-based) — Claude's choice"):
- Use min-max normalization across the batch of input results: `normalized = (x - x_min) / (x_max - x_min)` for each signal independently
- When x_max == x_min (single file or zero-range batch), set normalized = 1.0 for all rows of that signal (avoids divide-by-zero; documents that uniform-quality batches give all members full credit)
- For face_count: when max=0, all rows get 0.0 (no faces anywhere — no signal)
- For resolution: signal = pixel_width * pixel_height; normalize across batch; tie behavior identical to others

Conftest helpers from Plan 01:
- `_make_sharp_jpg(path, size=(200, 200))` — checkerboard, blur_var > 10000
- `_make_blurry_jpg(path, size=(200, 200))` — solid 128, blur_var < 50
- `_make_near_duplicate(source_path, dest_path)` — GaussianBlur radius=1, JPEG q=85

    Public function `_compute_quality(path: str) -> dict`:
      - Result dict keys: `path`, `blur_score`, `pixel_width`, `pixel_height`, `face_count`, `error` — all initialized to None / None / None / None / None / None except path which is the input.
      - try: cv2.imread(str(path)). If returns None: set error="cv2.imread returned None" and return.
      - Convert BGR to gray via cv2.cvtColor(img, cv2.COLOR_BGR2GRAY). Set blur_score = float(cv2.Laplacian(gray, cv2.CV_64F).var()).

    Public function `compute_quality_scores(paths: list[str], max_workers: int, progress_cb: Callable[[int, int], None] | None = None) -> Iterator[dict]`:
      - Mirror the structure of `photoconsole/hasher.py:process_files` (line 154-212).
      - total = len(paths); completed = 0.
      - ThreadPoolExecutor(max_workers=max_workers) context.
      - Submit each path: `future_to_path = {executor.submit(_compute_quality, p): p for p in paths}`.
      - for future in as_completed(future_to_path): path = future_to_path[future]; try result = future.result() except Exception as exc: result = {"path": path, "blur_score": None, "pixel_width": None, "pixel_height": None, "face_count": None, "error": str(exc)}; completed += 1; yield result; if progress_cb: progress_cb(completed, total).

    Public function `normalize_scores(results: list[dict]) -> list[dict]`:
      - For each non-error result, extract three signals: sharpness = blur_score, resolution = (pixel_width or 0) * (pixel_height or 0), faces = face_count.
      - Compute min/max for each signal across the batch (ignore None values: filter to error-free rows for min/max calc).
      - For each result, produce a dict: {path, sharpness_norm, resolution_norm, faces_norm}. Use min-max formula `(x - x_min) / (x_max - x_min)`. If x_max == x_min, set norm = 1.0 unless x_max == 0 (in that case set norm = 0.0 — no signal in batch).
      - For error rows (error is not None), set all three norms to 0.0 (so they cannot rank as keeper).
      - Length of output equals length of input.

    Public function `exif_completeness_score(record: dict) -> float`:
      - Accept dict-like; check `record.get("date_taken")` and `record.get("gps_lat")` and `record.get("gps_lon")`.
      - date_complete = bool(record.get("date_taken")); gps_complete = (record.get("gps_lat") is not None and record.get("gps_lon") is not None).
      - Return 1.0 if both true; 0.0 if both false; 0.5 if exactly one true.
