OpenCLIP API (per AI-SPEC §3 verified by research):
- `open_clip.create_model_and_transforms("ViT-B-32", pretrained="laion2b_s34b_b79k") -> (model, _, preprocess)`. Second return is text transform — unused.
- `model.encode_image(batch_tensor) -> torch.Tensor of shape (batch, 512)` (raw embeddings — NOT yet L2-normalized).
- L2 normalize: `features = features / features.norm(dim=-1, keepdim=True)`.
- Device selection: `torch.cuda.is_available() -> False` on this AMD Windows machine; always use `torch.device("cpu")` here.
- `Image.open(p).convert("RGB")` MUST be called (RESEARCH.md/AI-SPEC Common Pitfall 3: PNG opens RGBA, OpenCLIP needs 3-channel).

imagehash API:
- `imagehash.phash(PIL.Image, hash_size=8) -> ImageHash` (16-char hex via `str(h)`)
- `h1 - h2 -> int` Hamming distance

sklearn DBSCAN:
- `from sklearn.cluster import DBSCAN`
- `from sklearn.metrics.pairwise import cosine_distances`  ← NOT cosine_similarity
- `DBSCAN(eps=..., min_samples=..., metric="precomputed", n_jobs=-1).fit_predict(dist_matrix)`
- Returns array of int labels; -1 = noise

sklearn NearestNeighbors (sparse fallback):
- `from sklearn.neighbors import NearestNeighbors`
- `nn = NearestNeighbors(radius=eps, algorithm="ball_tree", metric="cosine", n_jobs=-1); nn.fit(embeddings); sparse_dist = nn.radius_neighbors_graph(embeddings, mode="distance")` → scipy sparse matrix
- Pass sparse_dist to `DBSCAN(metric="precomputed").fit_predict(sparse_dist)`

BLOB serialization (per AI-SPEC §3):
- `embedding_to_blob(emb)`: `emb.astype(np.float32).tobytes()`
- `blob_to_embedding(blob)`: `np.frombuffer(blob, dtype=np.float32).copy()` — `.copy()` is critical because frombuffer returns a read-only view of bytes

write_cluster_manifest analog: photoconsole/consolidator.py write_manifest (lines 335-392) — read in full.
- Phase 2 columns: `original_path, hash, destination_path, source_name`
- Phase 3 columns (DIFFERENT per RESEARCH.md Q4): `original_path, hash, source_name, cluster_id, quality_score` — no destination_path.
- BAT format identical: utf-8-sig encoding, \r\n line endings, header (@echo off, chcp 65001 >nul, :: comments), per-row routing (`del /f "..."` for local, `:: rclone deletefile ...` for rclone).
- Filenames: `cluster_deletion_manifest_{ts}.csv` and `cluster_delete_redundants_{ts}.bat` (different prefix from Phase 2 to avoid collision in the same directory).
- Returns tuple (csv_path, bat_path) of Path objects.

DBSCAN/cosine pitfall (RESEARCH.md Pitfall 3, AI-SPEC Common Pitfall 1): `cosine_similarity` returns values in [-1, 1] where 1=identical; DBSCAN interprets eps as a max DISTANCE; passing similarity inverts the logic silently. Must use `cosine_distances` which returns values in [0, 2] where 0=identical.

Sparse memory math (per AI-SPEC §4b.4): dense 50K x 50K x 4 bytes = 10GB; switch above ClusterConfig.sparse_threshold (default 50000) to NearestNeighbors radius graph.

ClusterGroup spec (per PATTERNS.md):
- cluster_id: int
- members: list[MediaFile] sorted by quality_score desc
- keeper: MediaFile (auto-pick — highest quality_score)
- redundants: list[MediaFile] (all non-keeper members)
- component_scores: dict[str, dict] of form {path_str: {sharpness, resolution, faces, exif, combined}}
