Critical eval dimensions to test (per AI-SPEC §5 Dimensions table):

1. **Cluster scene coherence** (cluster_purity >= 0.90) — critical
2. **Keeper pick accuracy** (auto-pick = labeled keeper in >= 80% of clusters) — critical

5. **Cluster size distribution** (max <= 50, p90 <= 20) — high

7. **Embedding determinism** (two runs produce bit-identical arrays) — medium (already covered by Plan 05 test_clustering.py::TestEmbedImages::test_embed_determinism)

Plan 05 already covers embedding determinism. This plan focuses on the 6 NEW eval dimensions not covered by unit tests (purity, keeper accuracy, burst recall, EXIF ranking, size distribution, throughput).

Synthesized fixture recipe (per RESEARCH.md Q7 + AI-SPEC §5 Reference Dataset):

A. Burst groups: 4 groups of 5 near-identical images each (use `_make_near_duplicate` chain: start with `_make_sharp_jpg(base)`, then `_make_near_duplicate(base, var_1)`, `_make_near_duplicate(var_1, var_2)`, etc. — each variation has Hamming distance ~2 from its predecessor).

B. Cross-event look-alike: 2 pairs of sharp checkerboard images at different sizes (200x200 vs 300x300) — should NOT cluster together.

C. Sharp vs blurry pairs (5 pairs): use `_make_sharp_jpg` for one, `_make_blurry_jpg` for the other. Same scene = same cluster expected.

D. EXIF-absent sharpest: 2 image rows constructed as dict (not real files needed if computing scores from raw signals): one with high blur_score=500 + NO date_taken/gps; one with low blur_score=100 + full EXIF (date_taken='2024', gps_lat=47.6, gps_lon=-122.3).

E. Solid-color hub image: 3 solid-color images (`_make_blurry_jpg` produces solid 128 by default; vary the fill color via override to get distinct hub images).

Ground truth dictionary (constructed inline in the test fixtures, NOT loaded from JSON — purely synthesized so tests are hermetic):
```
ground_truth = {
    "burst_A": ["burst_A/shot_0.jpg", ...],  # 5 shots
    "burst_B": [...],
    "burst_C": [...],
    "burst_D": [...],
    "sharp_blurry_1": ["pair_1/sharp.jpg", "pair_1/blurry.jpg"],
    ...
}
keepers = {"burst_A": "burst_A/shot_0.jpg", "sharp_blurry_1": "pair_1/sharp.jpg", ...}
```

Critical metrics formulas:
- Purity per cluster = (max member count of any ground-truth label in that cluster) / (cluster size).
  Overall purity = sum(per-cluster max member count) / total clustered files.
- Recall on burst groups = (count of burst pairs correctly co-clustered) / (total burst pairs in ground truth).
- Keeper accuracy = (count of clusters where auto-pick == labeled keeper) / (count of clusters with a labeled keeper).

Pytest markers registered in Plan 01: `critical` and `slow`.

Module-level skip: `pytest.importorskip("open_clip")` and `pytest.importorskip("torch")` at the top of the module. If CLIP is not installed, the entire file is skipped (eval requires real embeddings; synthesized images cannot substitute for the model output).

`@pytest.fixture(scope="module")` `clip_model` — loads model once per test session via `load_clip_model()`. Marks the test module as expensive but acceptable since these are eval gates.


    Helper functions at module top:

    `_make_burst_group(tmp_path, group_name, count=5)`:
      - Build a list of file paths burst_dir/shot_{i}.jpg for i in range(count).
      - Use `_make_sharp_jpg` (from conftest) to generate shot_0 (note: conftest helpers are accessible via simple call since conftest.py is auto-discovered).
      - For i in 1..count-1: use `_make_near_duplicate(shot_{i-1}, shot_{i})` to create a chain of near-identical images (Hamming distance ~2 per step).
      - Return the list of paths.

    `_make_sharp_blurry_pair(tmp_path, pair_idx)`:
      - Build pair_dir; create `sharp.jpg` (sharp checkerboard) and `blurry.jpg` (solid 128).
      - Return (sharp_path, blurry_path).

    `_make_hub_image(tmp_path, color: tuple[int, int, int])`:
      - Build a solid-color JPEG of given (R, G, B) — modify the blurry helper recipe to use the supplied color instead of 128.
      - Return path.

    `_compute_purity(labels: np.ndarray, ground_truth: dict[str, list[int]]) -> float`:
      - labels[i] = cluster_id assigned to file i (with -1 for noise)
      - ground_truth = {"group_label": [file_index_1, file_index_2, ...]}
      - For each predicted cluster c (excluding -1): count members per ground-truth label; max_label_count = max counts.
      - purity = sum(max_label_count for each cluster) / total clustered (non-noise) members.
      - Return float in [0.0, 1.0].

    Test functions:

    `@pytest.mark.critical` `def test_cluster_purity(tmp_path, clip_model)`:
      - Create 4 burst groups via _make_burst_group: burst_A (5), burst_B (5), burst_C (5), burst_D (5). Total 20 files.
      - Build ground_truth dict mapping group label to list of indices in the embed input order.
      - model, preprocess = clip_model.
      - Compute embeddings via embed_images(all_paths, model, preprocess, device="cpu", batch_size=10).
      - labels = cluster_embeddings(embeddings, eps=0.25, min_samples=2).
      - purity = _compute_purity(labels, ground_truth).
      - Assert purity >= 0.90. Log purity value on failure.

    `@pytest.mark.critical` `def test_burst_sequence_recall(tmp_path, clip_model)`:
      - Same 4 burst groups setup as above.
      - For each burst group: count pairs of members that ended up in the same cluster vs total pairs (n*(n-1)/2 per group).
      - recall = sum(co-clustered_pairs) / sum(total_pairs) across all burst groups.
      - Assert recall >= 0.90.

    `@pytest.mark.critical` `def test_keeper_pick_accuracy(tmp_path)`:
      - Create 5 sharp/blurry pairs (no CLIP needed — uses quality.py only).
      - For each pair: compute _compute_quality on sharp and blurry; normalize_scores on the 2-row list; compute_combined_score with default weights; pick the higher-score path as the auto-pick.
      - Compare auto-pick against labeled keeper (always the sharp one).
      - accuracy = correct / total. Assert >= 0.80 (actually should be 1.0 with default weights on pure sharp/blurry pairs, but threshold matches AI-SPEC eval dim).

    `@pytest.mark.critical` `def test_exif_absent_quality_ranking()`:
      - Build two normalized result dicts (no real files needed):
        - sharp_no_exif: {"path": "/a", "sharpness_norm": 1.0, "resolution_norm": 0.8, "faces_norm": 0.0}; exif=0.0

      - weights = QualityWeightsConfig() (defaults: 0.45/0.30/0.15/0.10)
      - sharp_score = compute_combined_score(sharp_no_exif, exif_score=0.0, weights=weights)
      - soft_score = compute_combined_score(soft_with_exif, exif_score=1.0, weights=weights)
      - Assert sharp_score > soft_score with diff > 5.0 (a meaningful margin so the test isn't sensitive to float noise).
