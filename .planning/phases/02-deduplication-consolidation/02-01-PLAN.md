| destination_path string → filesystem | Path traversal risk if destination_path contains ../ sequences |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-02-02 | Tampering | load_config: source_priority list entries | accept | Source priority names are strings compared against catalog source_name values; no filesystem or SQL use at parse time; validated at consolidation time |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new package installs in this plan; all stdlib + already-installed packages |
</threat_model>
