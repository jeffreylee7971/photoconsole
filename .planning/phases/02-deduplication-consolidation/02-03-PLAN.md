<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source file path → shutil.copy2 | Paths come from the catalog (written by trusted scan); destination path is user-configured |
| destination_root → filesystem | User-configured path; must not escape intended root |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | resolve_conflict: path construction | mitigate | Paths are built with pathlib arithmetic (parent / f"{stem}_{n}{suffix}"), never string interpolation; stays within desired_dest.parent |
| T-03-02 | Tampering | copy_and_verify: corrupt copy left on disk | mitigate | dest_path.unlink(missing_ok=True) called immediately on hash mismatch; source file never touched (D-13) |
| T-03-03 | Denial of Service | resolve_conflict: infinite loop if dest always exists with different hash | accept | In practice bounded by free disk space; n increments until filesystem rejects; acceptable for personal photo library scale |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new package installs; shutil is stdlib |
</threat_model>
